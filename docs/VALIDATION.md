# 验证范围

本记录为公开摘要，移除了真实网关地址、账户、设备连接端口和私有日志。主要测试日期为 2026-10-16、2026-10-21。

## 环境

- 真机：OPPO PGJM10，Android 13 / API 33，ARM64，Magisk 30.7。
- 原厂电话：`com.android.contacts` 13.20.0；可选 LSPosed 1.9.2。
- 隔离环境：Android 15 / API 35 x86_64 模拟器、本机 SIP fixture、虚构号码。
- 当前版本：0.2.1；Linphone SDK 5.4.124。

## 关键修正

- 系统通话账户状态改用已启用账户列表，兼容原厂权限限制。
- Linphone 服务状态与 Android 前台服务状态同步，避免 SDK 的无通话退前台逻辑导致服务异常。
- Magisk 安装使用管道传递 PackageManager 命令输入输出，兼容 Android 13 的受保护目录限制。
- 0.2.1 修正原厂弹性空隙权重，避免新增 SIP 按钮挤压实体卡按钮。
- 测试消息按 ID 与预期正文精确清理；保留原有配置和消息。

## 尚未完成的验证

- 原厂 SIP 按钮的一次内线测试进入 SET_DIALING 后收到网关 480，确认了路由，但没有据此确认语音接通。
- RTP 包流不等于人工双向听感、回声消除或音质验收。
- 原厂收件箱验证含本地注入的共用接收流程，不代替运营商端到端投递验证。
- SIP 200 / 202 只说明网关接受；不是终端送达回执。
- 未直接实现 IMS RPDU 编解码；上游需转换为文本 MESSAGE。
- 整夜待机、首次解锁前 VPN 连通性、Wi-Fi / 移动网络漫游，以及蓝牙、保持、DTMF 的完整验收仍需按设备测试。
- 未适配的 ROM、原厂电话版本或桌面不能直接套用以上结果。

具体实现边界见 [README](../README.md) 和 [安装说明](INSTALLATION.md)。
